ANNU AQUA ENGINEERS - Multi-page website

Files:
- index.html: Home page
- about.html: About Us page
- services.html: Service details page
- products.html: Products & Systems page
- gallery.html: Image gallery
- contact.html: Contact form (opens WhatsApp)
- style.css: Shared design and responsive layout

IMPORTANT:
1. Upload ALL these files to the root of the GitHub repository.
2. Rename/remove the old root index.html and replace it with this package's index.html.
3. GitHub Pages uses index.html as the home page.
4. Images load from external image URLs and require an internet connection. These are illustrative images, not verified company project photos.
5. Check the displayed email address and company details before publishing.
